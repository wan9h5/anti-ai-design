# 20 CSS px 图标控件：2.5.8 例外审查

**结论：并非每个 20 CSS px 图标控件都违反 WCAG AA。** 本次采用 `$anti-ai-design` 的 Review 流程及 AP041，区分图标图稿与实际指针命中区域。WCAG **2.2 的 2.5.8 Target Size (Minimum)，AA** 要求目标至少为 **24 × 24 CSS px**，但允许具名例外。**44 × 44 CSS px 属于 2.5.5 的 AAA 增强要求**，不能当作通用 AA 下限。2.5.8 是 WCAG 2.2 新增条款，不能将它直接归为 WCAG 2.1 AA 的要求。[规范依据](https://www.w3.org/TR/WCAG22/#target-size-minimum)

## 本次证据与边界

观察依据仅为题目提供的合成矩形尺寸和坐标，坐标为 CSS 像素中的左上角；未检查产品截图、源代码或实际点击行为。以下“通过”只指本次 **2.5.8 局部检查**，不代表页面或产品整体 WCAG AA 合规。误触影响尚未做用户测试。

## 具名例外

| 例外 | 成立条件 |
| --- | --- |
| Spacing（间距） | 对每个不足 24 × 24 的目标，以其边界框中心画直径 24 CSS px 的圆；这些圆不得与其他目标或其他不足尺寸目标的圆相交。不能只检查图标之间的视觉空白。 |
| Equivalent（等效） | 同一页面存在另一个满足本条标准的控件，可完成相同功能；仅有键盘操作方式不足以证明此例外。 |
| Inline（行内） | 目标位于句子中，或其尺寸受到非目标文字行高的约束；工具栏图标不能仅因紧凑而援引此例外。 |
| User Agent Control（用户代理控件） | 尺寸由用户代理确定，且作者未修改。原生元素这一标签本身不证明例外成立。 |
| Essential（必要） | 特定目标呈现对所传达信息是必要的，或有法律要求；风格偏好或节省空间不构成证明。 |

以上条件来自 [W3C 规范 2.5.8](https://www.w3.org/TR/WCAG22/#target-size-minimum)。[WAI Understanding 页面](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)用于解释测量方式，是说明性材料，规范正文才是要求来源。

## A–D 判定

| 控件 | 已知证据与计算 | 2.5.8 判定 | 例外与置信度 |
| --- | --- | --- | --- |
| A | 图稿 20 × 20；实际命中矩形 32 × 32。 | **通过尺寸要求。** 图稿尺寸不是目标尺寸。 | 不需要例外；基于提供的实际命中矩形，置信度高。 |
| B | 两个命中矩形分别为 `[0,20] × [0,20]`、`[40,60] × [0,20]`。圆心 `(10,10)`、`(50,10)`，半径均为 12；圆心距 40，大于直径 24，圆与圆不相交。每个圆心到另一个矩形最近距离 30，大于半径 12；圆与邻目标亦不相交。无其他邻居。 | **通过间距例外。** 两个目标本身均不足尺寸，但具备规定间距。 | Spacing 成立；置信度高。 |
| C | 两个命中矩形分别为 `[0,20] × [0,20]`、`[22,42] × [0,20]`。圆心 `(10,10)`、`(32,10)`，半径均为 12；圆心距 22，小于两半径之和 24，圆发生重叠。边缘空白 2 px，不能满足此配置下的圆检验。 | **间距例外不成立；在无其他适用例外的题设下，违反 2.5.8。** | 其他四项例外未获证据支持；尺寸和圆重叠计算置信度高。若真实产品另有例外证据，应重新判定。 |
| D | 仅图稿 20 × 20；实际命中区域、邻目标及间距未知。 | **无法判定。** 不可将图稿尺寸直接当作 AA 失败证据。 | 需测量实际命中区域和全部相关邻目标，并核实例外；当前无充分证据。 |

## 修复与验证

**C 是本次需要修复的明确候选。** 小且拥挤的目标可能增加相邻动作误触；这是标准要解决的风险，本次未测得实际误触率。优先级暂定 **moderate（中等）**：用户任务、动作后果和出现频率未知，不能据此声称关键任务受阻。

可保留 20 × 20 图稿，把实际命中区域扩大到至少 24 × 24，并调整布局确保点击区域有效且不互相遮盖；或保留两个 20 × 20 目标，将第二个目标左上角移至 `(24,0)` 或更远，使横向边缘空白至少 4 px。WAI 的同尺寸示例允许 4 px 间距；为避免边界及舍入争议，也可留更大间隔。这项 4 px 数字只适用于当前同高、同尺寸、水平排列的矩形配置，不能推广为任意布局的通用间距规则。

验证时应检查真实可激活区域，包括 padding、覆盖层、伪元素与事件接收区域；测量支持视口和交互状态下的所有邻目标，再逐项执行圆与圆、圆与目标检验。D 应先完成此测量。A、B 当前具备有效反例，应保留，不能为统一图稿大小而误报失败。键盘、名称、焦点、对比度等标准不在本次检查范围内。
