# 温度折线图轴范围审查

**结论：不必始终从零开始。本例可保留从 18°C 开始的纵轴。** 用户要比较温度随时间的变化；折线图用位置与连线表达趋势，清楚标注的非零范围有助于看清 18–22°C 的波动。不能把柱状图的零基线要求直接套到折线图。

提供的描述说明：这是连续时间趋势，纵轴起点 18°C 可见，单位和时间间隔已给出。这些都是应保留的有效设计。18°C 到 22°C 的温差为 4°C；不要用截取后的图高暗示倍数关系，也不要把摄氏温度表述为“增长约 22%”。

依据是技能中的 AP035 与 S16（UK Government Analysis Function 图表设计指导）：清楚披露且适合任务的折线图或点图可以采用非零范围。这是设计指导及其适用例外，不是要求所有图表归零的规范标准。

**没有证据支持将本例判为缺陷或要求修改。** 若后续图表用于跨面板比较，应检查各面板尺度是否一致；若结冰点 0°C 成为用户决策所需的阈值，则应展示该阈值或相应上下文。当前任务未提出这些需求。

建议验证：让读者读出起点、终点与温差，确认其理解为 18°C、22°C、升高 4°C，并检查等距温度刻度与实际时间位置是否正确。如果读者把画面高度当作绝对温度的倍数，再补充“纵轴范围 18–22°C”或直接标注温差。

审查仅基于提供的文字描述，未查看图像或运行界面；刻度间距、完整时间序列、视觉可读性与实际读者理解尚未验证。对“不必归零”的判断置信度高；没有对产品整体可访问性或实际理解效果作结论。
